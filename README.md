# AI Weather App

A Python desktop app that shows the current weather for any city and uses an AI model to suggest activities that fit the weather.

## Features

- Shows real-time weather data (temperature, conditions, etc.) for a city of your choice
- Recommends suitable activities based on the current weather, generated by an AI model
- Simple desktop interface built with Tkinter
- API keys are kept out of the code using environment variables

## Tech Stack

- **Language:** Python
- **GUI:** Tkinter
- **Weather data:** [OpenWeatherMap API](https://openweathermap.org/api)
- **AI recommendations:** [Groq API](https://groq.com/) with OpenAI's open-weight model `gpt-oss-120b`
- **Configuration:** `.env` file

## How It Works

1. You enter a city name in the app.
2. The app requests the current weather for that city from the OpenWeatherMap API.
3. The weather data is sent to the `gpt-oss-120b` model through the Groq API.
4. The model suggests activities that fit the weather, and the app displays them.

## Requirements

- Python 3.x
- An OpenWeatherMap API key
- A Groq API key

## Installation

1. Clone the repository:
```bash
   git clone https://github.com/[your-username]/[repo-name].git
   cd [repo-name]
```

2. Install the dependencies:
```bash
   pip install -r requirements.txt
```

3. Create a `.env` file in the project folder and add your keys:
```dotenv
   BASE_URL=https://api.openweathermap.org/data/2.5/weather
   API_KEY=your_openweathermap_api_key

   GROQ_BASE_URL=https://api.groq.com/openai/v1/chat/completions
   GROQ_API_KEY=your_groq_api_key
   GROQ_MODEL=openai/gpt-oss-120b
```

   > The `.env` file is listed in `.gitignore`, so your keys are never uploaded to GitHub.
